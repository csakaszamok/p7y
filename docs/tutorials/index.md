# Tutorials

Step by step, from nothing to an app with a link you can send to anyone. No server knowledge needed: your coding agent does the technical part.

- **[Put your app online with Claude Code](claude-code.md)**: install the p7y plugin once, then say *deploy this app* in any project. The easiest way.
- **[Put your app online with any agent](other-agents.md)**: Codex, Cursor, or Claude Code without the plugin, with a zip from Purgatory.
- **[Share your app with your team on the Hub](hub.md)**: list it where colleagues find, open and vote for it.

You need a Purgatory account: the address your team uses (for example `https://p7y.example.com`) and a sign-in. Someone in your team set Purgatory up; to set up your own, see [Install](../install.md).
