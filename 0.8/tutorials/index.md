# Tutorials

Step by step, from nothing to an app with a link you can send to anyone. No server knowledge needed: your coding agent does the technical part.

- **[Put your app online with Claude Code](https://p7y-dev.github.io/p7y/0.8/tutorials/claude-code/index.md)**: install the p7y plugin once, then say *deploy this app* in any project. The easiest way.
- **[Put your app online with any agent](https://p7y-dev.github.io/p7y/0.8/tutorials/other-agents/index.md)**: Codex, Cursor, or Claude Code without the plugin, with a zip from Purgatory.
- **[Share your app with your team on the Hub](https://p7y-dev.github.io/p7y/0.8/tutorials/hub/index.md)**: list it where colleagues find, open and vote for it.

You need a Purgatory account: the address your team uses (for example `https://p7y.example.com`) and a sign-in. Someone in your team set Purgatory up; to set up your own, see [Install](https://p7y-dev.github.io/p7y/0.8/install/index.md).
