# Tutorials

Step by step, from nothing to an app with a link you can send to anyone. No server knowledge needed: your coding agent does the technical part.

- **[Put your app online with Claude Code](https://csakaszamok.github.io/p9m/0.12/tutorials/claude-code/index.md)**: install the p9m plugin once, approve each project in the browser, then say *deploy this app*. The easiest way.
- **[Put your app online with any agent](https://csakaszamok.github.io/p9m/0.12/tutorials/other-agents/index.md)**: Codex, Cursor, or Claude Code without the plugin, with a zip from Purgatorium.
- **[Share your app with your team on the Hub](https://csakaszamok.github.io/p9m/0.12/tutorials/hub/index.md)**: list it where colleagues find, open and vote for it.

You need a Purgatorium account: the address your team uses (for example `https://p9m.example.com`) and a sign-in. Someone in your team set Purgatorium up; to set up your own, see [Install](https://csakaszamok.github.io/p9m/0.12/install/index.md).
